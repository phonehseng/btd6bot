## 01:35 — Build bloon paths the way the game does: straight, Bezier chain or cubic spline  (`fda1b2b`)

**Before** (01:34:44): `W strategy: giving up on step {'do': 'place', 'id': 'b2', 'kind': 'boomerang', 'role': 'dps', 'segment': [0.4, 1.0]} after 4 refused spots` — no footage

**Voiceover:**

- Build bloon paths the way the game does: straight, Bezier chain or cubic spline.
- Each path's point-source component decides how nodes become the route (read from GameAssembly): PolyLineNodes = straight lines (+ explicit Curve children), BezierLineNodes = anchor/handle/handle/anchor chains sampled with MakeBezierPoints(division 30), CurvedLineNodes = natural cubic spline through the nodes (CubicSpline.FitParametric) resampled per samplesPer100Units. 94 spline and 35 Bezier paths were previously drawn as straight lines between control points, which put the 'track' in the wrong place on curvy maps.
